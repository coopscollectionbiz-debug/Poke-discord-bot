Projects and sources

  • Smogon X/Y Sprite Project — Generation 6 Black/White-style sprites and animations. Co-led by Layell and princessofmusic.
  • Smogon Sun/Moon Sprite Project — Generation 7 Black/White-style sprites and animations. Led by Layell; leParagon.
  • Smogon Sprite Project (Generation 8 onward) — Generation 8 and 9 Black/White-style sprites and animations. Led by G.E.Z.; leParagon.
  • Pokémon Showdown — Hosts the Smogon project sprites (gen5ani / gen5) and the type icons; credits at pokemonshowdown.com/credits.
  • PokéAPI sprites — Official Black/White sprites for #1–649, and a mirror of the Smogon project sprites.

The Generation 6–9 sprites are fan-made pixel art by the Smogon sprite project contributors, credited here as the projects ask. The Fairy type icon comes from Pokémon Showdown’s type icons, like the other 17.
